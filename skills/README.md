# skills/

Agent skills for working with Harness Hg from a coding agent: the three loops, bootstrapping
a team, onboarding a team repository. Install with `npx skills add factory-level/harness-hg`.
Each skill is a `SKILL.md` plus references; none is part of the runtime.

Manual: https://factory-level.github.io/harness-hg/docs/get-started/
