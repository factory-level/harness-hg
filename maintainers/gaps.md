# Gaps, deviations and defects

**What this page tells you:** every place the running system falls short of
Design, organised by the design page that makes the claim — plus the
defects that are nobody's design, just bugs.

This is the comparative layer. The subsystem pages describe what *is*; this page describes the
delta. Five statuses are used, and the distinction matters:

| Status | Means |
|---|---|
| **Absent** | The design describes something the code does not attempt |
| **Partial** | Some of it works; the rest is named here |
| **Contradicted** | The code does something the design says it must not |
| **Built** | No delta left, kept because the row records what closing it took |
| **Withdrawn** | Built, then deliberately removed — the reason is the row |

The **Evidence** column names the subsystem page that owns the citations. A dash there is
significant: **a gap with no owning page is something the code does not do at all**, so there is no
`path:line` to cite.

Where a decision already exists, the ADR column links it. This page never restates a decision — the
[decision log](../_docs/adr/CHANGES.md) has a Status column that is already an authoritative delta ledger.

The spine was re-keyed in the final pass (#671): the numbered design pages 01–17 were retired
in #604, and `_docs/design/` now holds `platform.md`, `vocabulary.md`, `cli.md`, the
`nexus-ui` set and `landing-docs-repo.md`. Each section below keys to the page that owns its
claims and notes the number it carried, so nothing that survived the re-key lost its history.
