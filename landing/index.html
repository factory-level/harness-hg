Agent bundles

Install the whole team.

Share agents with the tools and capabilities they need — together, as a reusable bundle. One declaration brings the team, what it ships, and what it depends on.

How bundles work

GitOps-native

Orchestrated by the GitOps tools you already know.

Keep the workflow close to the repositories, reviews, and automation your team already uses. Mercury writes a record into Git and opens the pull request; Argo CD applies what merges and keeps the cluster matching it. No bespoke controller — reconciliation is off-the-shelf.
