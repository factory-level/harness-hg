Features

What Mercury gives you.

The record is the product: everything a fleet is stays visible in Git and reversible by revert. These are the capabilities that make that a working surface rather than a directory of files.

The capabilities

Agent Bundles Share and install complete agent teams — the agents, the apps they run beside, and the secrets they need — as one reviewable bundle. Fleet Canvas One canvas draws every agent, tool, person and note in the project — who is working, how they connect, and what is happening. Communication Agents publish events and register for the ones they need — a declared, reviewable event surface instead of point-to-point integrations. Backups Every agent’s state is backed up on a schedule, and restore is a rehearsal, not a hope. Repository Sharing Agent capabilities live in repositories — declared, versioned and shareable across projects.
