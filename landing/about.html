About

Why Mercury exists.

Harness Hg is a Hermes Agent plugin that turns an agent declaration into a GitOps record. One command renders the agent and everything around it into Git as a pull request; Argo CD applies that record and keeps it applied.

The idea

The record is the product.

A fleet of agents should be fully described in Git — reviewable, reproducible, and reversible by revert. And nothing in Mercury runs a control loop to make that true: reconciliation belongs to Argo CD and the External Secrets Operator, machinery operators already know. Anything that would need a controller of its own is the wrong answer.

The whole agent, not just the pod: the agent, the apps beside it, the secrets it needs, the events it exchanges and how it is exposed are rendered as one record.

A capability that cannot be declared does not exist.

In the open

Built in public, by Factory-level.

The project is developed in the open on GitHub. Every decision is written down with its cost, the documentation records what actually exists — including every place the system falls short of its own design — and the devlog tells the build story as it happens, wrong turns included.

Mercury is built by Factory-level. Questions, issues and contributions are welcome on GitHub.
