# Use cases

**What this page tells you:** three real shapes of agent team, and what differs between
them.

The same model covers all three. What changes is how much of it you use.

| Use case | Shape | Read it for |
|---|---|---|
| [Minimal agent](minimal.md) | One agent, nothing optional | the smallest thing that works |
| [Software project agent](software-project.md) | One agent, mounted against a codebase | installing against a repository you already have |
| [Marketing team](marketing.md) | Four agents, two bundled, two hosted services | what a production team looks like |

Read [minimal](minimal.md) first. Then [marketing](marketing.md) for the model fully used.
[Software project](software-project.md) is for an agent whose job is a codebase.
