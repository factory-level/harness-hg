# Get Started

**What this page tells you:** which loop is yours, and the page that walks it.

Everyone starts with **[Install the tools](install-the-tools.md)**. Then pick a loop. Each
loop has one front-door command and ends in a proof.

| You want to | Front door | Read |
|---|---|---|
| Build an agent team and run it locally | `hg dev` | [Build an agent team](dev-quickstart.md) |
| Create your own Agent Team Repo, no cluster | `hg bundle init` | [Agent Team Repo](agent-team-repo.md) |
| Host a real environment | `hg env new` | [Host an environment](host-an-environment.md) |

Developers live in the first two and hand a repo to whoever runs the environment. A
platform admin walks the third. A coding agent can drive the same loops:
[Agent Skills](agent-skills.md).
