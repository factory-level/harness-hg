## The compile/emission flow

A zero-custom-controller GitOps control plane for AI agent teams. Nothing here runs a control
loop — Argo CD (ApplicationSet + AppProject) and the External Secrets Operator do all
reconciliation. The path from a declaration to a running pod:

- **Hermes path** (frozen legacy): `hermes profile install` fires the registered hook
  (`plugin/gitops_emitter/__init__.py`) → `plugin/gitops_emitter/harness/hermes.py` reads the
  intent files, checks secrets, merges defaults/extension/overrides, and renders → 
  `plugin/gitops_emitter/gitrepo.py` publishes (commit or PR).
- **Eve path**: no install hook exists, so the caller emits —
  `python -m gitops_emitter.emit_cli` builds the record
  (`plugin/gitops_emitter/harness/eve.py` `build_eve_record`), run by the Pulumi `EveAgents`
  component or by `hg`, and publishes through the **same** `emitter.publish_record`, so the
  GitOps repository cannot tell the runtimes apart.
- Either way the destination repo gains `profiles/<name>/profile.yaml` — **plain Helm values**,
  one top-level `spec:` block, no CRD; its identity is its directory name
  (`{{.path.basename}}`).
- `infra/gitops-template/bootstrap/applicationset.yaml` (plus the per-surface generators in
  `bootstrap/applicationsets/`) turns each record into an Argo CD Application, layering two
  value files in order: `values/cluster-values.yaml` (environment, WHERE) then `profile.yaml`
  (application, WHAT).
- The harness charts realize the workload: records stamp bare chart names (`spec.chart`) and
  the ApplicationSet templates map the name to its parent — `eve-*` →
  `harness/eve/charts/…`, else `harness/hermes/charts/…`
  ([ADR 0160](../adr/0160-harness-chart-migration.md)); `hermes-profile` renders the
  StatefulSet and one child Application per `spec.apps[]`.

Provisioning ahead of all of this is `state/` + `infra/` (three config-gated Pulumi stages) —
[bootstrap.md](bootstrap.md).

## Source-of-truth boundaries

Three kinds of file live in this tree, and hand-editing the wrong kind is the classic failure:

| Kind | Files | Regenerated by |
|---|---|---|
| Authored | everything not listed below | — |
| Generated | `_docs/wiki/reference/profile-record.md`, `_docs/wiki/reference/contracts/*.md` (except `index.md`) | `make docs` (`docs-drift` gates) |
| Generated | `_docs/wiki/reference/cli/` (whole directory) | `make cli-docs` from `cli/src/commands.ts` (`cli-docs-drift` gates) |
| Generated | `infra/src/control-flow/generated-contract.ts` | `make contract-types` (`contract-types-drift` gates) |
| Generated | `nexus-ui/src/theme/theme.css` | the nexus-ui build from `nexus-ui/design/tokens.json` (theme-drift gate in its CI job) |
| Projected | `control-plane/nexus/dist/` | `cd nexus-ui && bun run build && bun run build:standalone` (byte-compared) |
| Projected | `control-plane/nexus/chart/files/` | `infra/scripts/sync-nexus-chart.sh` |
| Projected | the alerting-lib subchart copies inside consumer charts | `infra/scripts/sync-alerting-lib.sh` (`alerting-lib-drift` gates) |
| Projected | render-test goldens | `infra/scripts/render-test.sh --update` (never "fixed" by editing expected output) |

Version pins have exactly one home: `versions.json` (ADR-63) — `cli/src/lib.ts` and
`infra/src/control-flow/config.ts` import it, and `cli/tests/versions.test.ts` fails on any
second literal copy. The platform version itself is derived from commit subjects
(`infra/scripts/derive-version.py`, `make version`).

## The root table

Every top-level root, its boundary, and when new work lands there:

| Root | Owns | New work goes here when… |
|---|---|---|
| `agent-bundle-contracts/` | The frozen versioned contracts (21 groups; `agent-team/` is the authored surface of an agent-team repo, ADR 0178). Version dirs never mutate. | it changes what an agent bundle may declare. |
| `charts/` | **Only** the #672 compat trio (`monitoring`, `secret-tester`, `test-page`) — record-carried old paths, class `compat-copy`. | never — it shrinks to deletion with [#672](https://github.com/factory-level/harness-hg/issues/672). |
| `cli/` | `hg`: one directory per subject, `commands.ts` the manifest, `cli/loops/` the executable walkthroughs, `cli/test-env/charts/` the fixture workloads, `cli/schemas/evals/` the non-deployment eval contract. | an operator loop needs a verb. No loop, no merge. |
| `control-plane/` | Fifteen platform-owned component dirs + `planes.yaml`; charts homed per the boundary gate. | the platform (not a persona, not a harness) must run it for every environment. |
| `_docs/` | `adr/` + `design/` + `architecture/` (this tree) + `wiki/` (the only published tree) + `site/` (build output). | per the `_docs/README.md` contract. |
| `examples/` | Reference authorings + the negative `invalid-*` proof fixtures; part of the e2e-offline gate. | a contract needs a demonstration or a refusal proof. |
| `harness/` | One directory per harness — charts, image, `harness.yaml` gateway declaration. Hermes is frozen. | it drives a specific runtime; the platform stays harness-agnostic. |
| `infra/` | The bootstrap Pulumi program, `gitops-template/`, and `scripts/` — the gate machinery. | it provisions, emits, gates, or validates. |
| `landing/` | The static marketing site + devlog (hand-written HTML/CSS/JS). Untouched by the refactor. | marketing, never product truth. |
| `maintainers/` | The unpublished honesty ledgers: `built.md`, `gaps.md`, `observability-coverage.md`, `landing.md`, `final-pass/`. | a build unit, gap, or coverage row changes. |
| `nexus-ui/` | The rebuilt frontend, own bun workspace + CI job; builds `control-plane/nexus/dist`. | it renders; data stays behind the plugin-API / plan seams. |
| `plugin/` | `gitops_emitter/` (both runtime drivers + `emit_cli.py`) and `tests/` — the only pytest root. Slated to move into the Pulumi code ([#681](https://github.com/factory-level/harness-hg/issues/681)). | the emit pipeline changes (until #681 re-homes it). |
| `state/` | The state-backend Pulumi stack: per-agent state buckets, deploy SAs, IAM, backup buckets — rooted in the manual bucket + KMS. | the state/identity chain changes. |

Root-level files that carry weight: `versions.json` (the pin surface),
the ops repo's environment reference, `PRODUCT.md`, `CODEOWNERS`, and the gitignored-but-present local credentials (`.env`,
`harnesshg.*.private-key.pem` — inputs to local runs, regenerated by nothing).

## Eve at the Cloudflare edge (landed 2026-08-25)

Eve agents reach the edge over the environment's one shared control-plane tunnel
([ADR 0156](../adr/0156-eve-shared-tunnel.md)): the eve-agent chart renders its plain Ingress
under `providers.ingress: cloudflare`, byte-identical to the `ingress` render — a render-test
equality gate pins that claim (`harness/eve/charts/eve-agent/templates/_helpers.tpl`
`eve.ingressGuard`; the chart moved from `infra/charts/` at
[ADR 0160](../adr/0160-harness-chart-migration.md)). The eve-runtime image is served from
`ghcr.io/example/eve-runtime` (the ghcr name was never published),
pinned in `versions.json`. The factory fleet declares four Eve twins beside the live Hermes
personas in `infra/Pulumi.factory.yaml` (`marketing-{manager,research,engagement,sre}-eve`,
`runtime: eve`) — declared in stack config; emitting them is a factory `pulumi up` (stage 2),
and none runs on the factory environment yet (`maintainers/gaps.md`).

## Known defects

- **No agent on the factory environment runs on Eve** — the second runtime is proven on the local loop
  only (`maintainers/gaps.md`).
- **CI is manually disabled repo-wide** (`.github/workflows/DISABLED.md`,
  [#737](https://github.com/factory-level/harness-hg/issues/737)) — every gate this page names
  runs only when a developer runs it.
- The product rename is incomplete by design: frozen schema names, the `hermes-gitops-*` Pulumi
  project names, the `hermes-*` chart names inside `harness/hermes/`, and the Nexus wire id
  `hermes-gitops` all still carry the old name
  (`maintainers/final-pass/naming-scheme.md` is the disposition ledger).
- `charts/` is a standing exception to its own boundary gate until
  [#672](https://github.com/factory-level/harness-hg/issues/672) deletes the trio.
